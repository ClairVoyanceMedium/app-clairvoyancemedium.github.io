Suivez les étapes affichées ci-dessous dans l’ordre. Vous n’avez pas à chercher dans plusieurs menus au hasard.

Installation Android guidéeLes étapes restent visibles en permanence. Celle à faire maintenant est entourée en or.
1

Autoriser votre navigateur

Android doit autoriser le navigateur utilisé à installer l’application.

Dans l’écran Android, activez « Autoriser depuis cette source », puis revenez ici.
2

Samsung : vérifier le Bloqueur automatique

Sur Samsung, le Bloqueur automatique peut empêcher l’APK même si le navigateur est autorisé.

Si Samsung affiche « Application inconnue bloquée », touchez OK, revenez ici et utilisez ce bouton.
2

Télécharger l’application

Le fichier officiel est ClairVoyanceMedium.apk.

Télécharger ClairVoyanceMedium
3

Ouvrir puis installer

À la fin du téléchargement, touchez la notification ou la barre « Téléchargement terminé », puis Ouvrir et enfin Installer.

Si une fenêtre de sécurité apparaît : lisez le message, touchez OK ou Paramètres, puis revenez à cette page. L’aide restera affichée.
4

Après l’installation

Une fois la barre d’installation terminée, touchez Ouvrir si Android le propose. Sinon ouvrez la liste des applications et touchez l’icône ClairVoyanceMedium.com.

Installation terminée

Vous devez maintenant voir l’icône ClairVoyanceMedium.com parmi vos applications. Un appui sur l’icône ouvre directement votre site dans l’application.
