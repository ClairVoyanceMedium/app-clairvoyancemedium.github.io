Installation Android guidéeCompatible avec les téléphones Android et les principaux navigateurs. Aucun bouton de cette page n’essaie d’ouvrir une application de téléchargements externe.
1

Télécharger l’application

Le fichier officiel est ClairVoyanceMedium.apk et fait environ 46 Mo.

Télécharger ClairVoyanceMedium
2

Suivre puis ouvrir le téléchargement

Le téléchargement est géré directement par votre navigateur Android.

Pour voir l’avancée : faites glisser votre doigt du haut de l’écran vers le bas pour ouvrir le volet de notifications. Vous y verrez la progression de ClairVoyanceMedium.apk.

Quand le téléchargement est terminé, touchez la notification ClairVoyanceMedium.apk ou le message « Ouvrir le fichier », puis choisissez Installer.

Si Android indique que votre navigateur n’est pas autorisé à installer des applications, touchez Paramètres, activez « Autoriser depuis cette source », puis revenez au fichier APK.
!

Protection du téléphone

Sur certains appareils Samsung Galaxy, le Bloqueur automatique peut empêcher l’installation d’un APK téléchargé hors des boutiques d’applications.

Sur Samsung uniquement : Paramètres → Sécurité et confidentialité → Bloqueur automatique → désactivez-le temporairement. Revenez ensuite ouvrir l’APK.
3

Après l’installation

Touchez Ouvrir si Android le propose. Sinon ouvrez la liste des applications et touchez l’icône ClairVoyanceMedium.com.

Installation terminée

L’icône ClairVoyanceMedium.com doit maintenant apparaître parmi vos applications. Au premier lancement, l’application pourra proposer l’activation des notifications.
