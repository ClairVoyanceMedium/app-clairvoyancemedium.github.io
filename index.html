Suivez les étapes affichées ci-dessous dans l’ordre. La page détecte automatiquement Android ou iPhone/iPad.

Installation Android guidéeLes étapes restent visibles en permanence. Celle à faire maintenant est entourée en or.
1

Autoriser votre navigateur

Android doit autoriser le navigateur utilisé à installer l’application.

Activez « Autoriser depuis cette source », puis revenez ici.
2

Samsung : vérifier le Bloqueur automatique

Sur Samsung, le Bloqueur automatique peut empêcher l’APK même si le navigateur est autorisé.

Si Samsung affiche « Application inconnue bloquée », touchez OK, revenez ici et utilisez ce bouton.
2

Télécharger l’application

Le fichier officiel est ClairVoyanceMedium.apk.

Télécharger ClairVoyanceMedium
3

Ouvrir puis installer

À la fin du téléchargement, touchez Ouvrir puis Installer.

Si Android affiche un message de sécurité, touchez OK ou Paramètres, puis revenez ici.
4

Après l’installation

Touchez Ouvrir si Android le propose. Sinon ouvrez la liste des applications et touchez l’icône ClairVoyanceMedium.com.

Installation terminée

L’icône ClairVoyanceMedium.com doit maintenant apparaître parmi vos applications.

Installation iPhone / iPad sans compte développeurCette méthode installe une icône ClairVoyanceMedium.com sur l’écran d’accueil et ouvre le site en plein écran, sans barre d’adresse Safari.
1

Utiliser Safari

Ouvrez cette page avec Safari sur l’iPhone ou l’iPad. Apple autorise le téléchargement manuel d’un profil de configuration depuis le Web.

Si vous êtes déjà dans Safari, passez directement à l’étape 2.
2

Télécharger le profil ClairVoyanceMedium

Le profil contient uniquement le raccourci plein écran vers www.clairvoyancemedium.com et votre icône officielle.

Télécharger le profil iPhone / iPad
Après le téléchargement, iOS affiche « Profil téléchargé ». Installez-le rapidement : iOS supprime un profil non installé après quelques minutes.
3

Installer dans Réglages

Ouvrez Réglages → Profil téléchargé → Installer en haut à droite. Saisissez le code de l’iPhone si demandé, puis touchez encore Installer et OK.

Si « Profil téléchargé » n’apparaît pas, allez dans Réglages → Général → VPN et gestion de l’appareil.
4

Ouvrir ClairVoyanceMedium.com

L’icône officielle apparaît sur l’écran d’accueil. Touchez-la : le site s’ouvre comme une app Web en plein écran.

Installation iPhone / iPad terminée

L’icône ClairVoyanceMedium.com est maintenant installée. Cette méthode n’a pas besoin de compte Apple Developer et ne dépend pas d’une signature IPA de 7 jours.
