Application iPhone / iPad

ClairVoyanceMedium.com

Cette version est conçue pour fonctionner comme une application web sur l’écran d’accueil et pour pouvoir recevoir des notifications push sur iOS/iPadOS compatibles.

1

Ajouter à l’écran d’accueil

Sur iPhone/iPad, ouvrez cette page dans Safari, touchez Partager, puis Ajouter à l’écran d’accueil.

Apple exige cette étape pour autoriser les notifications Web Push sur iPhone et iPad.
2

Ouvrir depuis l’icône

Fermez Safari puis ouvrez ClairVoyanceMedium.com depuis l’icône ajoutée à l’écran d’accueil.

3

Autoriser les notifications

Une fois ouverte depuis l’écran d’accueil, touchez le bouton ci-dessous. iOS affichera sa demande officielle d’autorisation.

4

Ouvrir le site officiel

Votre site reste accessible directement depuis cette application.
